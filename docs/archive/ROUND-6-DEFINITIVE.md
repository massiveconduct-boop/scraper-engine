## Issue 2: BrowserPool Lifecycle — CLOSED

**Status: PASS.** lease() async context manager restores invariant §1.1.6.

```
$ .venv/bin/pytest tests/live/test_browser_pool_lifecycle.py -v -s
LIFECYCLE: pre=0 mid=1 final=0 PASS
1 passed in 6.81s
```

**Implementation:** `pool.lease(proxy, domain)` — async context manager. Guarantees `release()` on exit. Healthy release re-queues live context for reuse. Unhealthy release (exception) tears down browser. `acquire()` includes idle timeout eviction (max_idle_seconds=300).

**Per-domain session state:** `_load_session(ctx, domain)` / `_save_session(ctx, domain)` stubs on lease boundary. Prevents cross-domain cookie leakage with warm reuse. Full implementation deferred pending `browser_sessions` schema + Postgres client in BrowserPool.

**Limitation:** Domain session stubs are pass-through. Warm contexts share cookies across domains until wired. Single-domain scraping unaffected. **Decision owner:** product owner.
